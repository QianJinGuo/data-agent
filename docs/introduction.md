# 产品介绍

## 什么是 Data Agent

Data Agent 是一个基于大语言模型的企业级数据智能体平台，将自然语言查询转换为 SQL 执行，并以可视化图表呈现结果，同时支持端到端的营销策略自动化。

## 核心能力

### 1. NL2SQL 智能问数

用户用自然语言提问，系统自动：
1. 理解查询意图（数据检索 / 对比 / 趋势 / 归因）
2. 生成准确的 SQL 查询语句
3. 执行查询并返回结构化数据
4. 推荐最优可视化图表
5. 生成自然语言数据解读
6. 自动检测数据异常

### 2. 营销策略助手

端到端营销自动化：
1. **目标解析** — 理解营销活动目的
2. **人群圈选** — 对接 CDP 构建目标受众
3. **方案生成** — 按人群/渠道/内容维度生成多套方案
4. **策略配置** — 生成最佳触达时机、渠道优先级、内容变体
5. **任务执行** — 配置并输出可执行的触达任务

## 适用场景

| 场景 | 例子 |
|------|------|
| 业务数据查询 | "各区域销售额是多少？" |
| 趋势分析 | "近6个月的销售趋势如何？" |
| 对比分析 | "华东区和华北区的业绩对比" |
| 归因分析 | "为什么东北区上月销售下滑？" |
| 异常检测 | "哪些指标出现显著异常？" |
| 营销活动创建 | "创建高价值客户召回活动" |
| 定时数据推送 | "每周一早上9点推送上周销售报告" |

## 技术特性

- **多 Agent 编排** — 基于 LangGraph 的状态机编排，支持复杂工作流
- **多数据集支持** — 跨多个数据集联合查询，智能识别数据源
- **对话记忆** — 多轮对话上下文保持，理解追问
- **异常检测** — 统计方法（z-score/IQR）自动发现数据异常
- **灵活部署** — 支持本地/Docker/云端部署
- **REST API** — 标准 API 接口，易于集成到现有系统

## 组成部分

| 组件 | 说明 |
|------|------|
| NL2SQL Pipeline | 自然语言转 SQL 的 6 节点 LangGraph |
| Marketing Pipeline | 营销策略自动化的 5 节点 LangGraph |
| DataAgentOrchestrator | 统一编排器，自动路由问题类型 |
| FastAPI REST API | 标准 REST 接口 |
| React 前端 | 交互式 Web 界面 |
| SQLAlchemy Connectors | 支持 ClickHouse / MySQL / Doris |

## 与火山引擎数据智能体的关系

本产品复刻了火山引擎 Data Agent 的核心能力，包括：
- NL2SQL 智能问数 Agent（意图理解 → SQL 生成 → 执行 → 归因 → 解读）
- 营销策略助手 Agent（目标 → 人群 → 方案 → 策略 → 触达）

在火山引擎基础上，扩展了：
- 开源代码实现，便于二次开发
- 标准 REST API，易于集成
- 独立的 React 前端，定制化界面
- 多数据库连接支持
